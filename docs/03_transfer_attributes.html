Pseudonode dissolution → piece graph traversal → true-shape geometry assembly

Model links are dissolved across pseudonode chains, then each dissolved link’s geometry is assembled by traversing the physical piece graph from A’s snap position to B’s snap position. Model attributes are transferred to the resulting true-shape LineStrings.

3 Part A — Pseudonode Dissolve

Collapse chains of model links connected through pseudonodes. Each dissolved link spans from one real node to another; pseudonodes along the way are absorbed. Every model link attribute column (besides A, B, geometry) rides along onto the dissolved output, taken from each chain’s first constituent link.

Links whose both endpoints are already real nodes appear as single-constituent chains.

FT_2027/LN_2027 are the only columns pseudonode classification (Stage 1) guarantees are uniform across a chain’s constituents. Every other column is checked for agreement in multi-constituent chains; disagreements are tallied per column rather than silently dropped — see the breakdown below.

5 Part C — Assemble True-Shape Chains

For each dissolved link A→B, perform a constrained BFS through the piece graph from A’s snap coordinate to B’s snap coordinate. The BFS cannot traverse through real_junction nodes other than B — this ensures the path stays within the physical bounds of a single dissolved link.

Some dissolved links have no route between A and B that avoids every other real junction — typically an ordinary cross-street the link legitimately passes through, not a bleed into an adjacent dissolved link. When the constrained BFS fails, assemble_chain_relaxed retries with the real-junction restriction dropped, using shortest-path-by-length instead of unweighted BFS so the recovered route still follows the physically shortest path. Links recovered this way are tagged dissolved_relaxed rather than dissolved so they remain distinguishable for QA.

Show the code 
print(f"Assembling {len(gdf_dissolved):,} dissolved links …")

trueshape_geometries: list = []
trueshape_methods: list[str] = []
n_unresolved = 0
n_no_path = 0
n_relaxed = 0

for i, (_, row) in enumerate(gdf_dissolved.iterrows()):
    if i > 0 and i % 2000 == 0:
        print(f"  {i:,} / {len(gdf_dissolved):,} …")

    a_n, b_n = int(row["A"]), int(row["B"])
    a_coord = node_coord_lookup.get(a_n)
    b_coord = node_coord_lookup.get(b_n)

    if a_coord is None or b_coord is None:
        n_unresolved += 1
        a_pt = node_geom_lookup.get(a_n)
        b_pt = node_geom_lookup.get(b_n)
        fallback = LineString([a_pt, b_pt]) if (a_pt and b_pt) else None
        trueshape_geometries.append(fallback)
        trueshape_methods.append("unresolved_no_snap")
        continue

    pieces = assemble_chain(piece_graph, a_coord, b_coord)
    used_relaxed = False
    if pieces is None:
        pieces = assemble_chain_relaxed(piece_graph, a_coord, b_coord)
        used_relaxed = pieces is not None

    if pieces is None:
        n_no_path += 1
        a_pt = node_geom_lookup.get(a_n)
        b_pt = node_geom_lookup.get(b_n)
        fallback = LineString([a_pt, b_pt]) if (a_pt and b_pt) else None
        trueshape_geometries.append(fallback)
        trueshape_methods.append("unresolved_no_path")
    else:
        merged = linemerge(pieces) if len(pieces) > 1 else (pieces[0] if pieces else None)
        trueshape_geometries.append(merged)
        trueshape_methods.append("dissolved_relaxed" if used_relaxed else "dissolved")
        if used_relaxed:
            n_relaxed += 1

n_dissolved = trueshape_methods.count("dissolved")
print(f"\nDissolved (true-shape):       {n_dissolved:,} ({n_dissolved/len(gdf_dissolved):.1%})")
print(f"Dissolved (relaxed fallback): {n_relaxed:,} ({n_relaxed/len(gdf_dissolved):.1%})")
print(f"Unresolved (no snap):         {n_unresolved:,}")
print(f"Unresolved (no path):         {n_no_path:,}")

Links whose both endpoints are already real nodes appear as single-constituent chains.

`FT_2027`/`LN_2027` are the only columns pseudonode classification (Stage 1)
guarantees are uniform across a chain's constituents. Every other column is
checked for agreement in multi-constituent chains; disagreements are tallied
per column rather than silently dropped — see the breakdown below.

```{python}
print("Dissolving pseudonodes …")

print(f"Original links:   {len(gdf_links):,}")

```

## Part B — Build Piece Graph

Build a networkx Graph from the physical link pieces. Each node is labelled
`real_junction`, `pseudonode`, or `internal` based on whether it coincides
with a snapped model node and whether that node is a pseudonode.

```{python}
print("Building piece graph …")
piece_graph = build_piece_graph(gdf_pieces, gdf_nodes_snapped)

n_nodes = piece_graph.number_of_nodes()
n_edges = piece_graph.number_of_edges()
type_counts = {}
for _, attrs in piece_graph.nodes(data=True):
    t = attrs.get("node_type", "internal")
    type_counts[t] = type_counts.get(t, 0) + 1

print(f"Piece graph: {n_nodes:,} nodes | {n_edges:,} edges")
print(f"Node types:")
for t, cnt in sorted(type_counts.items()):
    print(f"  {t:20s}: {cnt:,}")
```

## Part C — Assemble True-Shape Chains

For each dissolved link A→B, perform a constrained BFS through the piece graph
from A's snap coordinate to B's snap coordinate. The BFS cannot traverse through
`real_junction` nodes other than B — this ensures the path stays within the
physical bounds of a single dissolved link.

Some dissolved links have no route between A and B that avoids every other
real junction — typically an ordinary cross-street the link legitimately
passes through, not a bleed into an adjacent dissolved link. When the
constrained BFS fails, `assemble_chain_relaxed` retries with the real-junction
restriction dropped, using shortest-path-by-length instead of unweighted BFS
so the recovered route still follows the physically shortest path. Links
recovered this way are tagged `dissolved_relaxed` rather than `dissolved` so
they remain distinguishable for QA.

```{python}
print(f"Assembling {len(gdf_dissolved):,} dissolved links …")

trueshape_geometries: list = []
trueshape_methods: list[str] = []
n_unresolved = 0
n_no_path = 0
n_relaxed = 0

for i, (_, row) in enumerate(gdf_dissolved.iterrows()):
    if i > 0 and i % 2000 == 0:
        print(f"  {i:,} / {len(gdf_dissolved):,} …")

    a_n, b_n = int(row["A"]), int(row["B"])
    a_coord = node_coord_lookup.get(a_n)
    b_coord = node_coord_lookup.get(b_n)

    if a_coord is None or b_coord is None:
        n_unresolved += 1
        a_pt = node_geom_lookup.get(a_n)
        b_pt = node_geom_lookup.get(b_n)
        fallback = LineString([a_pt, b_pt]) if (a_pt and b_pt) else None
        trueshape_geometries.append(fallback)
        trueshape_methods.append("unresolved_no_snap")
        continue

    pieces = assemble_chain(piece_graph, a_coord, b_coord)
    used_relaxed = False
    if pieces is None:
        pieces = assemble_chain_relaxed(piece_graph, a_coord, b_coord)
        used_relaxed = pieces is not None

    if pieces is None:
        n_no_path += 1
        a_pt = node_geom_lookup.get(a_n)
        b_pt = node_geom_lookup.get(b_n)
        fallback = LineString([a_pt, b_pt]) if (a_pt and b_pt) else None
        trueshape_geometries.append(fallback)
        trueshape_methods.append("unresolved_no_path")
    else:
        merged = linemerge(pieces) if len(pieces) > 1 else (pieces[0] if pieces else None)
        trueshape_geometries.append(merged)
        trueshape_methods.append("dissolved_relaxed" if used_relaxed else "dissolved")
        if used_relaxed:
            n_relaxed += 1

n_dissolved = trueshape_methods.count("dissolved")
print(f"\nDissolved (true-shape):       {n_dissolved:,} ({n_dissolved/len(gdf_dissolved):.1%})")
print(f"Dissolved (relaxed fallback): {n_relaxed:,} ({n_relaxed/len(gdf_dissolved):.1%})")
print(f"Unresolved (no snap):         {n_unresolved:,}")
print(f"Unresolved (no path):         {n_no_path:,}")
```
