Reassemble the full node/link tables as drop-in replacements for the raw WFv1000 MasterNet shapefiles

Every raw model node keeps its full attribute record, with only its coordinate resolved through the same tiered snap cascade used for centroid connectors (main network snap -> CC/external nearest-point snap -> raw model coordinate fallback), so unsnapped or future node classes fall through safely without code changes. The final link table concatenates the model-attributed true-shape roadway pieces from 03_transfer_attributes.qmd with the centroid connector links from 02_create_link.qmd, dropping every lineage/QA-only column. Both outputs are written as ESRI Shapefiles using the field schema (names, order, DBF widths/precision) copied directly from the original MasterNet shapefiles, so they can be swapped in for the originals as-is.

3 Part A — Resolve Final Node Coordinates

Every node keeps its full raw attribute record; only X/Y/geometry are replaced, resolved through the same priority cascade build_centroid_connector_links already applies (raw model coordinate as the base fallback, overwritten by CC/external-station nearest-point snaps, overwritten in turn by the main greedy network snap). Listing sources lowest-priority first, highest last, means a future improved snapping pass or a brand-new node class is handled by adding one more entry to snap_sources — no other code changes.

Show the code 
snap_sources = [
    (
        "ext_snapped",
        gdf_ext_snapped[gdf_ext_snapped["snap_resolved"]],
        "N", "x_snap", "y_snap",
    ),
    (
        "cc_snapped",
        gdf_cc_snapped[gdf_cc_snapped["snap_resolved"]],
        "N", "x_snap", "y_snap",
    ),
    (
        "network_snapped",
        gdf_nodes_snapped[gdf_nodes_snapped["snapped"].fillna(False).astype(bool)],
        "N", "snapped_x_round", "snapped_y_round",
    ),
]

coord_lookup, tier_lookup = resolve_node_coordinates(gdf_network_nodes, snap_sources)

tier_counts = pd.Series(tier_lookup).value_counts()
print("Node coordinate resolution tier:")
print(tier_counts.to_string())
assert len(coord_lookup) == len(gdf_network_nodes)

node_ids = gdf_network_nodes["N"].astype(int).to_numpy()

with fiona.open(PATHS["schema_node_shp"]) as src:

4 Part B — Build Final Link Table

Only fully model-attributed rows go into the replacement file — the qa_status == "matched" roadway pieces and the centroid connectors. The qa_status in {“endpoints_only”, “a_only”, “b_only”, “neither”} rows in links_trueshape.gpkg are real UGRC geometry with no model link behind them at all (no valid A/B), so they cannot populate a schema that requires model node ids and model attributes — they stay out of this replacement file (they remain available in links_trueshape.gpkg for QA/inspection).

Show the code 
gdf_matched = gdf_links_trueshape[gdf_links_trueshape["qa_status"] == "matched"].copy()
print(f"Matched roadway pieces: {len(gdf_matched):,}")
Matched roadway pieces: 15,880
Show the code 
with fiona.open(PATHS["schema_link_shp"]) as src:
    link_schema_props = list(src.schema["properties"].keys())

gdf_matched_final = conform_to_reference_schema(
    gdf_matched, link_schema_props, rename_map=LINK_RENAME_MAP,
)
gdf_cc_final = conform_to_reference_schema(
    gdf_centroid_connectors, link_schema_props, rename_map=LINK_RENAME_MAP,
)

gdf_links_final = pd.concat([gdf_matched_final, gdf_cc_final], ignore_index=True)
gdf_links_final = gpd.GeoDataFrame(gdf_links_final, geometry="geometry", crs=CRS_UTM)

print(f"gdf_links_final: {len(gdf_links_final):,} rows, {len(gdf_links_final.columns)} columns")
print(f"  = {len(gdf_matched_final):,} matched roadway + {len(gdf_cc_final):,} centroid connectors")
assert list(gdf_links_final.columns) == [*link_schema_props, "geometry"]
assert len(gdf_links_final) == len(gdf_matched_final) + len(gdf_cc_final)
assert gdf_links_final.geometry.isna().sum() == 0
